# visual identity
- All icons and wallpaper should be pixilated in an 8bit graphic style.
- use higgsfield mcp to create the icons and wallpapers
- All the icons should be movable or able to drag and drop
- The cursor should alsp be pixilated and should remain pointed until it is holding where it is close
- The images should be in pngs.

# Coding style
- Do not use any external dependencies without permission.
- Do not commit any changes without permission. 

# Verification and Validation
- use playwright and vitest to test the ui works.
- Check every feature independently before shipping.
